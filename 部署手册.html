教务管理系统 · 部署文档（零基础上手版）

这份文档是写给完全没有接触过这个项目、电脑也是新装的人看的。 你不需要懂 Java、不需要懂数据库，照着从第 1 章做到第 5 章就行，全程大约 40 分钟（其中大部分时间在下载软件）。

〇、先看这个：一共只有 4 步

顺序 你要做的事 大概耗时 会不会出问题
1 安装 JDK 21（Java 运行环境） 10 分钟 注意勾选“添加到 PATH”，见第 2 章
2 安装 MySQL（数据库） 15 分钟 记住你设置的密码，建议就用 123456
3 双击 2-初始化数据库.bat 1 分钟 需要输入 MySQL 密码
4 双击 3-启动系统.bat 1 分钟 浏览器会自动打开系统

做完这 4 步，系统就跑起来了。 以后每次使用，只需要双击 3-启动系统.bat。

登录入口只有一个：http://localhost:8080/login（打开后按账号自动进入对应后台）。

登录用的演示账号（密码统一 123456）：

遇到报错别慌：绝大多数问题都在第 8 章「常见问题」里，按现象对号入座即可。 如果卡在某一步，把报错窗口的截图发出来，比描述文字快得多。

一、准备工作

1.1 电脑要求

项目 要求 说明
操作系统 Windows 10 / 11（64 位） Windows Server 也可以
内存 4 GB 以上，建议 8 GB 系统本身占用约 500 MB
磁盘空间 至少 5 GB 空余 交付包 72 MB + JDK 约 300 MB + MySQL 约 1.5 GB
网络 仅安装阶段需要联网 装好以后，断网也能正常使用（因为是本机单机运行）

拿到的是压缩包 教务管理系统-交付包-v1.0.zip，右键 → 全部解压，建议解压到：

注意两点： 1. 路径里尽量不要有空格（例如别放在 D:\我的 文件\ 这种带空格的目录），虽然大多数情况没问题，但能避开就避开。 2. 不要放在 C 盘 Program Files 里，那里的权限限制会导致脚本无法正常工作。

二、第 1 步：安装 JDK 21

为什么要装：这个系统是用 Java 写的，Windows 本身不带 Java，必须装一个「Java 运行环境」才能运行。

2.1 下载

任选一个来源，三个都是官方/正规镜像，下载的都是 JDK 21（64 位 Windows）：

来源 地址 说明
清华大学镜像（国内快，推荐） https://mirrors.tuna.tsinghua.edu.cn/Adoptium/21/jdk/x64/windows/ 进目录后下载文件名形如 OpenJDK21U-jdk_x64_windows_hotspot_21.0.x_x.msi 的那个 .msi
Eclipse Temurin 官网 https://adoptium.net/temurin/releases/?version=21 平台选 Windows、架构 x64、包类型 JDK、版本 21，下载 .msi
微软 OpenJDK 21 https://learn.microsoft.com/java/openjdk/download 下载 microsoft-jdk-21.x.x-windows-x64.msi

三个都行，装哪个都可以，效果一样。国内网络推荐第一个。

2.2 安装

双击下载好的 .msi 文件，然后：

  1. 一路点 Next（下一步）
  2. 出现功能列表的那一页要特别注意（不同安装包这一步长得不一样，但要点是一样的）：
选项（名称可能略有差别） 要设置成
Add to PATH / 设置 PATH 这一项必须是选中状态
Set JAVA_HOME variable / 设置 JAVA_HOME 手动选成 Will be installed on local hard drive（将会安装到本地硬盘）
JavaSoft (Oracle) registry keys 保持默认即可

界面上是一个带三角箭头的树形列表，点开每个小图标，如果显示的是 ❌ 或者空白，就点它一下，选择「将会安装到本地硬盘」。 3. 点 Install，等待完成，点 Finish。

2.3 验证是否装好

  1. 按键盘 Win + R，输入 cmd，回车，会打开一个黑色命令行窗口
  2. 输入下面这行，回车：

java -version

  1. 成功的样子（版本号只要 ≥ 21 就行，通常是 21.0.x）：

openjdk version "21.0.7" 2025-04-15 OpenJDK Runtime Environment (build 21.0.7+6) OpenJDK 64-Bit Server VM (build 21.0.7+6, mixed mode)

  1. 失败的样子：提示 'java' 不是内部或外部命令，也不是可运行的程序

→ 说明第 2.2 步的 Add to PATH 没勾上。两个解决办法： - 简单：卸载 JDK，重新安装一遍，这次务必把 Add to PATH 选中； - 或者：重启一下电脑再试（有时环境变量需要重启才生效）。

三、第 2 步：安装 MySQL

为什么要装：系统里的学生、成绩、考勤等所有数据都存在数据库里，MySQL 就是那个数据库。

3.1 下载

打开 https://dev.mysql.com/downloads/installer/，下载 MySQL Installer for Windows。

页面上有两个文件，选大的那个（约 300~450 MB，文件名形如 mysql-installer-community-8.0.xx.msi）， 小的那个是「联网安装版」，安装过程中还要下载，容易失败。

版本选 8.0 或 8.4 最稳（这两个是长期支持版）。 如果你只能下到 9.x，也没问题 —— 本系统已在 MySQL 9.0.1 上实测通过。

下载页面会提示登录 Oracle 账号，不用登录，往下找一行小字 No thanks, just start my download. 点它就能直接下载。

3.2 安装

  1. 双击 .msi，等待它解压并打开安装向导
  2. Choosing a Setup Type（选择安装类型）：选 Server only（只装服务器）

想同时要一个图形化管理工具，可以选 Custom 并额外勾上 MySQL Workbench。 只是运行系统的话，Server only 最省事，出错的环节最少。

  1. 点 Next → Execute，开始安装（1~3 分钟）
  2. Type and Networking：直接 Next - Config Type 保持 Development Computer - Port 保持 3306（不要改，系统默认连的就是这个端口）
  3. Authentication Method：选第一项 Use Strong Password Encryption（默认就是它），Next
  4. Accounts and Roles：设置 root 密码

⚠️ 这一步很关键，记牢你输入的内容。

  • 建议直接输 123456 —— 系统默认就是用这个密码，装完不用改任何配置。
  • 如果安装程序提示密码太简单、不允许，就改成一个复杂点的，例如 Root123456。 这种时候把密码记下来，第 4 章会用到（要填进配置文件）。

下面那个 MySQL User Accounts 不用加，留空即可。

  1. Windows Service：保持勾选 Configure MySQL Server as a Windows Service， Windows Service Name 默认（一般是 MySQL80）， 并勾选 Start the MySQL Server at System Startup（开机自动启动，强烈建议勾）。
  2. 后面几步一路 Next → Execute → Finish。

3.3 验证是否装好

按 Win + R → 输入 services.msc → 回车，在服务列表里找名字带 MySQL 的服务：

要看的内容 应该是
状态 正在运行（如果没有，右键 → 启动）
启动类型 自动

能在这里看到「正在运行」，数据库就算装好了。

安装时如果没把 MySQL 加到 PATH，命令行里敲 mysql 会提示找不到命令 —— 这不影响使用， 我们的脚本会自动去常见目录里找它。

四、第 3 步：初始化数据库（双击脚本）

这一步是把系统需要的数据（22 张表、213 个用户、39 条菜单）写进 MySQL。

4.1 操作

进入解压出来的目录（例如 D:\教务管理系统），双击 2-初始化数据库.bat。

窗口中会依次发生：

  1. 提示「确认继续请输入 y 然后回车」 → 输入 y 回车
  2. 自动查找 mysql.exe（找不到会让你手动粘贴路径，见下方说明）
  3. 提示「请输入 MySQL 的 root 密码」
  • 如果你按建议设的是 123456，直接回车即可；
  • 如果设的是别的（例如 Root123456），就输入那个密码再回车；
  • 注意：输入密码时屏幕上不会显示任何字符（连星号都没有），这是正常的，输完直接回车。

  1. 脚本自动执行三个 SQL 文件，屏幕会出现进度： - [1/3] 正在创建表结构 ... - [2/3] 正在写入演示数据（数据较多，请耐心等待 10~30 秒）... - [3/3] 正在补充教师管理菜单 ...

  2. 最后会显示校验结果，成功的样子：

``` 正在校验结果 ... 表数量 = 22 用户数 = 213 菜单数 = 39

============================================================ 数据库初始化完成！下一步请双击「3-启动系统.bat」 ```

看到 表数量 = 22，这一步就成功了。

如果脚本提示「没有自动找到 mysql.exe」： 打开文件资源管理器，进入 MySQL 的安装目录，通常是 C:\Program Files\MySQL\MySQL Server 8.0\bin， 找到 mysql.exe，点击上方地址栏复制完整路径，再粘贴到脚本窗口里回车。 完整路径形如 C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe。

如果提示 Using a password on the command line interface can be insecure： 这是 MySQL 的正常提醒，可以直接忽略。

4.2 用图形化工具导入（备选方案）

如果脚本方式总是不行，也可以用图形化工具手动导入。 以 MySQL Workbench 为例（Navicat 操作类似）：

  1. 打开 Workbench → 双击本机连接（Local instance MySQL80）→ 输入 root 密码
  2. 菜单 File → Open SQL Script → 选择 数据库脚本\01_schema.sql → 点⚡执行按钮
  3. 重复第 2 步，依次执行 02_data.sql、03_add_teacher_menu.sql
  4. 顺序不能变（先建表，再插数据，最后补菜单）

也可以用命令行（在交付包目录打开命令行窗口后执行三行）： bat mysql -uroot -p --default-character-set=utf8mb4 < 数据库脚本\01_schema.sql mysql -uroot -p --default-character-set=utf8mb4 < 数据库脚本\02_data.sql mysql -uroot -p --default-character-set=utf8mb4 < 数据库脚本\03_add_teacher_menu.sql 执行后按提示输入密码。

五、第 4 步：启动系统（双击脚本）

双击 3-启动系统.bat，会出现两个窗口：

窗口 作用 要不要关
教务管理系统 - 启动 启动引导，完成后会自动打开浏览器 可以关掉
教务管理系统 - 服务窗口 系统的运行窗口，里面有运行日志 别关！关掉就等于关掉系统

启动脚本会自己等系统就绪（约 5~15 秒），然后自动用默认浏览器打开登录页。

启动时，「服务窗口」的最上面会打印出登录入口地址，长这样：

============================================================
  教务管理系统 启动成功
  登录入口：http://localhost:8080/login
============================================================

照这一行里的地址打开即可（如果你改过端口，这里打印出来的就是新端口，不用自己换）。

如果浏览器没自动打开，手动打开浏览器，在地址栏输入：

http://localhost:8080/login

5.1 登录（只有一个入口）

系统只有这一个登录入口：http://localhost:8080/login

输入账号和密码即可，不需要选身份 —— 系统按账号自动判断身份， 然后进入该身份自己的后台：能看到的功能菜单、能查到的数据范围都不一样。

身份 账号形式 进入后台后能做什么
学生 学号 我的课表、选课退课、我的成绩、我的考勤、请假、公告
班主任 教师工号 本班学生、本班成绩录入、请假审批、本班考勤（只管自己带的班）
教务处 教务处账号 学籍、课程、排课、成绩审核、考勤、公告等全校教务数据
管理员 管理员账号 教务处全部功能 + 用户、角色、菜单、操作日志

登录成功后地址栏会变成 http://localhost:8080/dashboard（工作台）。 四种身份用的是同一个入口，但进去后看到的界面和左侧菜单完全不同 —— 这是正常的， 说明系统已经认出你的身份了。

登录用的演示账号见 附录 A。

5.2 其他有用的地址

地址 说明
http://localhost:8080 系统首页（会自动跳到登录页）
http://localhost:8080/doc.html 接口文档（给开发者看的技术资料，普通人可以不看）

5.3 关闭系统

双击 4-停止系统.bat，脚本会自动找到并关闭系统进程。 或者直接关掉那个「服务窗口」也可以。

注意：关掉浏览器不等于关掉系统，系统还在后台运行。

六、日常使用

6.1 每次开机的正确顺序

① 确认 MySQL 服务在运行
   （如果第 3.2 步勾选了「开机自动启动」，这一步通常不用管）

② 双击「3-启动系统.bat」

③ 浏览器自动打开 → 登录使用

④ 用完：双击「4-停止系统.bat」

6.2 做个桌面快捷方式（可选）

右键 3-启动系统.bat → 发送到 → 桌面快捷方式。 以后直接从桌面启动，不用每次都进目录找。

6.3 数据存在哪里

所有数据都在 MySQL 的 academic_affairs 数据库里。 系统关闭、重启都不会丢数据。想备份数据，在 MySQL Workbench 里选中这个库，用 Data Export 导出即可。

⚠️ 重新双击 2-初始化数据库.bat 会清空并重建数据库，原有数据会丢，日常不要重复运行它。

七、修改配置（改密码 / 改端口）

配置文件是：

D:\教务管理系统\程序\application.properties

用记事本打开它（右键 → 打开方式 → 记事本），你会看到两个需要关心的参数：

7.1 改数据库密码

如果你安装 MySQL 时设的不是 123456，必须改这里，否则系统连不上数据库：

# 把 123456 改成你安装 MySQL 时设置的 root 密码
spring.datasource.password=123456

改完按 Ctrl+S 保存即可（文件名保持 application.properties 不变；用记事本直接改、直接保存，不要用「另存为」去改编码）。

7.2 改服务端口

如果启动时提示 8080 端口已被占用，把端口改成别的（例如 8081）：

server.port=8081

改完访问地址也要跟着变：http://localhost:8081

脚本不用改。 1-检查环境.bat、3-启动系统.bat、4-停止系统.bat 每次运行都会自动读取这里的 server.port， 所以你把它改成 8081 之后，脚本检查的端口、自动打开的网址都会跟着变成 8081，无需手工同步。

7.3 是否在登录页显示演示账号（可选）

登录页默认不显示任何演示账号。如果你要拿系统做演示，希望登录页出现 「四个身份的演示账号一键填充」小块，在同一个配置文件里加一行：

aas.demo-accounts=true

保存后按 7.4 重启即可生效，不需要重新打包。演示账号本身见 附录 A。

7.4 改完必须重启

配置文件只在启动时读取一次，所以改完要： 先双击 4-停止系统.bat，再双击 3-启动系统.bat。

八、常见问题（按现象查）

8.1 启动相关

现象 原因 解决办法
双击 bat 窗口一闪就没了 脚本前置检查未通过 先双击 1-检查环境.bat，按它给出的提示处理
提示 'java' 不是内部或外部命令 JDK 没装，或装的时候没勾 Add to PATH 见 2.2 / 2.3，重装 JDK 并勾选 Add to PATH
提示 当前 Java 版本过低：1.8.0_xxx 电脑上装的是旧版 Java（Java 8 / 11 / 17 都不行） 本系统的程序用 Java 21 编译，必须安装 JDK 21，见 2.2
启动窗口报 Port 8080 was already in use 8080 被别的软件占用（或系统已在运行） 若系统已在运行 → 直接用浏览器打开即可；否则按 7.2 改端口
启动窗口报 Communications link failure 或 Connection refused MySQL 服务没启动 Win+R → services.msc → 找到 MySQL 服务 → 右键启动
启动窗口报 Access denied for user 'root'@'localhost' 数据库密码不对 按 7.1 把 application.properties 里的密码改成你实际的密码，重启系统
启动窗口报 Unknown database 'academic_affairs' 第 4 章没做，或没做成功 重新双击 2-初始化数据库.bat
等很久浏览器没自动打开 启动较慢，或浏览器没被识别 手动打开浏览器输入 http://localhost:8080
启动窗口里最后一行是 Started AcademicAffairsApplication in x seconds，但页面打不开 说明后端是好的，问题在浏览器/地址 确认地址是 http://localhost:8080（不是 https，也别漏掉冒号）

九、局域网内多台电脑一起用（可选）

默认只能在装了系统的这台电脑上访问。想让同一个局域网的其他电脑也能打开：

第 1 步 · 放行防火墙（以管理员身份打开「命令提示符」，执行）：

netsh advfirewall firewall add rule name="教务管理系统" dir=in action=allow protocol=TCP localport=8080

第 2 步 · 查看本机 IP：命令行里执行 ipconfig，找到 IPv4 地址，例如 192.168.1.100。

第 3 步 · 其他电脑访问：浏览器打开 http://192.168.1.100:8080

注意：多台电脑共用同一个数据库，数据是共享的；请确保这台电脑一直开着。

十一、给开发者：改代码并重新打包

只使用系统的话，这一章可以跳过。

11.1 开发环境运行（前后端分离，可热更新）

见 源代码\运行指南.md，里面有 IntelliJ IDEA 的完整步骤（导入 Maven 工程、指定 JDK 21、 开启注解处理、一键运行/调试）。项目根目录 .run\ 下已预置好运行配置。

快速版：

cd 源代码
start-backend.bat      :: 后端，默认 8080
start-frontend.bat     :: 前端，默认 5173，访问 http://localhost:5173

11.2 打成「单文件运行版」（就是交付包里那个 jar）

:: 1) 先构建前端
cd 源代码\frontend
npm install            :: 首次需要
npm run build          :: 产物输出到 frontend\dist

:: 2) 再打包后端（-Pwith-frontend 会把 dist 打进 jar）
cd ..\backend
mvn clean package -Pwith-frontend -DskipTests

:: 3) 产物
::    backend\target\academic-affairs-system.jar  ← 这个 jar 自带前端界面

关键点：不带 -Pwith-frontend 打出来的只是纯后端 jar，需要另外部署前端； 带上这个参数，前端界面会被复制进 jar 内部的 static/ 目录， 这样 java -jar 就能同时提供界面和接口，部署方不需要装 Node.js。
